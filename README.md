# gun

Процедурные 3D-вьюверы стрелкового оружия на three.js. Каждый файл в `weapons/`
самодостаточен: геометрия, материалы, система кастомизации `__ATTACH` и звук
собраны внутрь одного HTML. Внешняя зависимость только одна — three.js 0.166
через `importmap` с unpkg, поэтому для запуска нужна сеть.

## Модели

| Файл | Оружие |
| --- | --- |
| `weapons/ak74_modular.html` | АК-74 |
| `weapons/akm.html` | АКМ |
| `weapons/m416.html` | M416 |
| `weapons/scar-h.html` | FN SCAR-H Mk 17 |

## Карты

| Файл | Карта |
| --- | --- |
| `maps/angar.html` | ANGAR-07 — ангар 80 x 50 м с двухэтажным каркасным shoot house |

Карта собирается процедурно из того же набора приёмов, что и оружие: все
текстуры рисуются в canvas, геометрия мержится по материалам.

### Что есть на карте

Ангар 80 x 50 м, внутри — каркасное здание 38 x 24 м на два этажа
(наружные стены, коридоры-анфилады, атриум на два света по центру).

Пять точек интереса:

| Точка | Объект |
| --- | --- |
| СЗ угол | мачта с пиратским флагом на два этажа, полотнище колышется |
| СВ угол | гараж: машины на первом этаже, рампа и стоянка на втором |
| ЮЗ угол | вертолётная площадка с ограждением по периметру и вертолётом |
| ЮВ угол | водонапорная башня и склад ГСМ под навесом |
| центр | штабель морских контейнеров под кран-балкой, внутри атриума |

Техника (машины, вертолёт) — статичные укрытия без интерактива.

На второй этаж ведут четыре наружные лестницы с улицы (с ангара) плюс
крытый переход из гаража и две внутренние лестницы.

Укрытия: стенки из бетонных блоков, бытовки, бетонные трубы, ящики с
песком, строительные леса, отбойники, мешки с песком, бочки, поддоны.

## Локальный запуск

Открывать файлы через `file://` нельзя — ES-модули и importmap требуют
http-происхождения. Поднимите статический сервер из корня репозитория:

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/weapons/akm.html` или
`http://localhost:8080/maps/angar.html`.

## Управление

### Оружие

| Клавиша | Действие |
| --- | --- |
| `Пробел` | огонь (удержание — очередь в авторежиме) |
| `R` | перезарядка |
| `X` | смена режима огня |
| `C` | фонарь вкл/выкл |
| `Z` | ЛЦУ вкл/выкл |
| `TAB` | панель кастомизации модулей |
| `← →` | перебор модулей в выбранном слоте |
| `B` | сложить/разложить сошки и приклад |

`C` и `Z` работают даже на «голом» оружии: если подходящего прибора нет,
клавиша сама вешает планку и фонарь либо ЛЦУ.

Режимы огня различаются по оружию и соответствуют реальным переводчикам:

| Оружие | Режимы |
| --- | --- |
| АК-74, АКМ | предохранитель → автоматический → одиночный |
| M416 | предохранитель → одиночный → очередь по 3 → авто |
| SCAR-H Mk 17 | предохранитель → одиночный → автоматический |

### Карта ANGAR-07

| Клавиша | Действие |
| --- | --- |
| `W A S D` | движение |
| `мышь` | обзор |
| `Space` | вверх (в полёте) / прыжок (пешком) |
| `Ctrl` | вниз |
| `Shift` / `Alt` | быстрее / медленнее |
| `G` | переключение ходьба ↔ полёт |
| `V` | noclip — проход сквозь геометрию (отладка) |
| `N` | день / ночь |
| `Esc` | освободить мышь |
| `F3` | счётчик FPS |

Стены, перекрытия, кровля и техника непроходимы в обоих режимах: в полёте
тело сжимается до компактной сферы, чтобы пролетать в дверные проёмы, но
сквозь преграды не проходит. `V` отключает проверку для отладки.

### Проверка карты

Автотест непроходимости геометрии прогоняется в открытой странице карты:

```sh
python3 -m http.server 8080 &
node tools/collision-test.mjs > /tmp/ct.js
agent-browser eval "$(cat /tmp/ct.js)"
```

Скриншот с произвольной точки: `tools/shot.sh out.png x y z tx ty tz`.

## Запуск в headless-браузере

Сцены используют WebGL, которого в headless-Chrome по умолчанию нет. Нужен
программный рендер через SwiftShader:

```sh
chrome --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader
```

Без этих флагов страница показывает «Не удалось собрать модель: Error creating
WebGL context.» — это ограничение окружения, а не ошибка модели.
